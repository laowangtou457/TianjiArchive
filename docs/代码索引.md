# 代码索引 —— 天玑档案管理系统

> 版本 1.0.0 ｜ 本文是**全部工程代码的模块级索引**：每个目录/模块的职责、关键文件与入口。

## 三、apps/extractor —— 文本抽取 Worker（异步）

`main.ts`（入口）→ `extract.processor.ts`（BullMQ 消费；`route()` 按 MIME/扩展名分发，public 供单测）→ `object.fetcher.ts`（S3 取原文件）→ `converters/`（格式转换：pdf/office/图片等；电子书三件套 `book.common.ts`（ZIP 解包/HTML 转文本/多编码解码，零依赖）＋ `epub.converter.ts`（container.xml→OPF→spine 顺序）＋ `mobi.converter.ts`（PalmDOC 解压/trailing 剥离/DRM·HUFF 显式报错））→ `es.indexer.ts`（写 ES）＋ `db.ts`（直连 PG）＋ `context.ts`（运行上下文）。单测：`__tests__/ebook.converters.spec.ts`（21 例，夹具独立实现）。

## 四、apps/cli-migrator —— 存量数据迁移 CLI

`cli.ts`（入口）→ `excel.reader.ts`（台账 Excel 解析）→ `file.matcher.ts`（电子文件匹配）→ `migrator.ts`（著录落库）→ `checkpoint.ts`（断点续跑）→ `report.ts`（迁移报告）。
