# 泰坦 DARMS2020 全量功能对照与差距清单（2026-11-17 重扫）

> 依据：泰坦 H2 库 `T_S_PRIVILEGE` 4394 条功能点实扫（339 个页面 / 4015 个按钮级功能点），
> 与天玑 Archive 当前代码（路由 22 个 + api 23 个模块）逐页比对。
> 结论：**确实没抄完**。此前 P1–P4 覆盖的是「增强版 JZQB 主干流程」；泰坦还有
> 批量操作 UI、导出/打印/编目、多门类、接收移交挂接、四性检测/ERMS、库房、
> 编研、自定义报表、分类模板等 **约 40 项功能** 未落地。

## 三、其它版本独有功能（JZQB 之外）

- **FZST 综合版**：会计档案/会计档案(案卷)、企事业/基建/实物/科技档案、虚拟库房、光盘管理、审批单管理、销毁批次、辅助实体管理设置
- **JYBB 综合版**：借阅全流程独立页（利用登记/外借单据/查档管理/审批中/查阅中/已完成）、销毁批次、档案移交、数据字典管理
- **SJCB 数据中心版**：库房上架三页（位置关联条目/条目关联位置/已上架/未上架）、销毁批次、统计管理
- **JBZB 标准版**：实体档案接收、统计管理
- **LYPT 利用平台**：利用者门户（未归电子/电子档案/未归实体/实体档案 四区检索，163+55+89+140 按钮）——天玑 /search 未区分利用者视角

## 四、差距汇总与分期建议

### 高频共性缺口（建议 P5，1–2 周量）
1. **批量操作 UI**：批量修改（API 已有）/批量替换/批量插入/调序 —— API 补替换与插入
2. **条目导出**：excel/xml（归档管理+案卷管理+卷内）；dbf 可降级为 excel
3. **打印**：条目打印、卷内打印、编目打印（复用 A4 打印框架 utils/print.ts）
4. **数据导入页面化**：批次→模板→确认→明细（复用批量导入脚本能力）
5. **保管期限表**独立管理页
6. **借阅补**：外借单据页、出入库登记、查阅中/已完成分组
7. **销毁批次管理**

### 门类扩展（P6）
8. 门类模板化著录（照片/录音/录像/资料/专业/会计档案，按 categoryCode 换著录表单与列表列）
9. 照片组管理、拆件/插件
10. 一文一件分类方案

### 交换与检测（P7）
11. 电子档案接收（接收包/确认/退回）
12. 电子档案移交（移交包/下载）
13. 电子文件挂接（批次/规则/预挂接）
14. 四性检测（设置+执行，真实性/完整性/可用性/安全性）
15. 长期保管 ERMS（封装包/计划任务/状态重置）

### 实体与增值（P8，按需）
16. 实体库房/电子库房/辅助实体/上架位置
17. 编研管理
18. 自定义报表（报表分类+字段设置）
19. 公告管理/下载中心
20. 档案分类模板（列表视图配置/著录视图分组/模板导入导出）
21. 元数据标准
22. 用户权限设置（按用户授权视图）
23. 利用者门户（LYPT 四区检索视角）

### 明确不抄
ExtJS UI、二维码识别/查询、光盘导出、补丁管理、密集架可视化（除非做实体档案）、日志导入 Excel
