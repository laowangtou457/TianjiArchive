# 泰坦 DARMS2020 功能对照与天玑增强方案

> 生成时间：2026-11-13
> 依据：`D:\Titansoft\DARMS2020` 安装目录实勘（H2 数据库 270 张表 + 4388 个权限点功能树 + titansbsda Web 应用 239 个 JSP + titansolr 配置）

## 一、泰坦系统概况

| 项 | 内容 |
|---|---|
| 产品 | 泰坦 DARMS 档案综合管理系统（2020-11 出厂，标准/高级版） |
| 形态 | .NET WPF 桌面客户端（CefSharp 内嵌 Web）+ Java/Tomcat 后端 + H2 单机库 |
| Web 应用 | `http://127.0.0.1:10511/titansbsda`（Struts + Ext JS 6 + jQuery 1.8） |
| 检索 | Apache Solr（`/titansolr`，solr.data.search=true） |
| 数据库 | H2（`jdbc:h2:tcp://localhost/titansdata`，titans_login/master_2016），270 张表 |
| 权限 | T_S_PRIVILEGE 4388 个功能点，按 CODE 前缀拼接成树（产品版→模块→页面→按钮） |
| 产品版 | 标准版 JBZB / 综合版 JYBB / 增强版 JZQB / 数据中心版 SJCB / 利用平台 LYPT |

**结论：能抄。** 泰坦的全部功能定义都在数据库功能树和表结构里，无黑盒。

## 二、泰坦功能清单（增强版 JZQB 全貌）

### 1. 档案收集
- **门类**：文书文件 / 案卷管理收集 / 电子文件收集 / 照片文件 / 录音文件 / 录像文件（每门类独立入口）
- **状态机**：`未处理 → 预归档 → 待审核 → 已归档`，旁路 `无需归档`（可撤回）
- **各状态按钮**：著录、编辑、查看、打印、删除、预归档/撤消预归档、确认归档、不通过、调序、批量修改/替换/插入、组合检索、全文检索、二维码识别/查询、归档设置、鉴定规则、保管期限表、期限依据文档
- **案卷收集**：案卷管理（著录卷内/显示案卷卷内所有/提交审核/卷内打印）、未编卷内（生成案卷）、已编卷内
- **OA 接收**：手工执行、查看封装包、计划设置、接收数据源配置、单位/分类设置、检测方案
- **数据导入**：建立批次、模板配置、确认、记录明细
- **档案接收 / 电子档案接收**：上传接收包、查看接收包、确认、退回、检测方案
- **电子文件挂接**：建立批次、规则设置、上传挂接包、预挂接管理、确认挂接

### 2. 档案管理
- **归档管理**（按门类）：著录/编目/盒管理/条目销毁/条目开放/导出 excel·xml·dbf
- **案卷管理**：生成案卷、数据转移、卷内打印
- **照片档案**：照片组管理、拆件、插件
- **录音/录像档案**：拆件、插件
- **资料管理 / 专业档案（平级+组卷两种）**
- **档案鉴定**：鉴定任务（增加/修改/删除/任务处理/统计/鉴定处置表）
- **开放数据管理**：未处理 → 条目开放 / 原文开放 / 不开放 / 再审查，开放批次，开放设置
- **销毁数据管理**：还原
- **全宗卷管理**
- **实体档案移交 / 电子档案移交**：移交包生成、查看、下载、检测方案
- **辅助实体管理**：入库、出库、装具管理
- **一文一件（分类方案）**

### 3. 档案保存
- **长期保存（ERMS）**：封装包查看（明细/文件/封装包）、手工执行、计划设置、任务设置、状态重置、检测方案
- **回收站**：还原、清空
- **电子库房**
- **备份与恢复**：在线备份、离线备份登记、恢复、备份策略
- **实体库房**：库房/库位初始化、进入库房（可视化密集架）

### 4. 档案利用
- **目录检索 / 分类检索 / 全文检索**
- **查借阅管理**：利用登记（申请单：利用者、用途、方式、天数、证件）→ 审批中 → 外借单据（归还/出入库）/ 查阅中 / 打印 / 已完成
- **统计报表管理 / 统计报表**（分类管理、报表设计、打印）
- **编研管理**：编研成果、发布/取消发布、下载
- **光盘导出**：生成光盘文件、下载
- **利用日志管理**

### 5. 系统管理
- 机构/用户/角色（功能权限+数据权限分离）、用户权限设置
- 日志管理（Excel 导入导出）
- **审批设置**：流程类型、环节流向设置、环节回调设置、环节权限管理
- **元数据标准**
- **档案分类模板**：档号设置、主题词、同义词、列表视图/字段排序、著录视图/字段分组、复制模板、导入导出模板、分类方案
- 全宗管理（统计/打印全宗信息）、分类管理
- 报表管理（数据源设置、报表样式上传下载）
- 鉴定标准管理（保管期限表）
- 四性检测设置（检测项配置）
- 数字字典管理、公告管理、下载中心、补丁管理、系统配置备份

## 三、天玑现状对照

| 泰坦功能域 | 天玑现状 | 差距 |
|---|---|---|
| 全宗/案卷/件三级模型 | ✅ 有（fonds/volume/item + 档号规则） | 基本齐 |
| 收集状态机 | ⚠️ 只有归档确认单点 | **缺 未处理→预归档→待审核→已归档 全链状态机** |
| 归档审核流 | ⚠️ ARCHIVE_CONFIRM 简单确认 | **缺 多环节审批流（环节流向/回调/环节权限）** |
| 著录 | ✅ ItemEditor | 缺 自定义字段/著录视图分组/列表视图配置 |
| 组合检索/全文检索 | ✅ ES 条件+全文 | 缺 分类检索入口、同义词、检索历史 |
| 批量修改/替换/插入 | ❌ | **缺**（批量导入只有外部脚本） |
| 借阅 | ✅ 申请/审批（R3/R4） | 缺 外借/归还/出入库/利用日志/打印利用单 |
| 鉴定/开放/销毁 | ⚠️ 有开放控制位 | **缺 鉴定任务、开放流程、销毁/回收站** |
| 移交接收/四性检测 | ❌ | **缺**（含封装包、检测方案） |
| OA 对接/挂接 | ❌ | 缺（可后置） |
| 长期保存 ERMS | ⚠️ extractor 有归档抽取 | 缺 封装包/计划任务/电子库房 |
| 实体库房/盒管理 | ❌ | 缺（如果只做电子档案可降级） |
| 编研/统计报表/光盘 | ❌ | 缺 |
| 元数据标准/分类模板/字典 | ⚠️ 有档号规则 | 缺 字段级元模型 |
| 机构/用户/角色 | ✅ R0-R4 + grants | 缺 数据权限按机构树细分 |
| 预览 | ✅ epub/txt/pdf/office | 领先泰坦 |
| UI | ✅ 现代 React | 领先泰坦（Ext JS 2010 风） |

## 四、增强实施方案（建议分期）

### P1 归档工作流 + 状态机（对齐泰坦核心，2 周量）
- item 加 `stage` 字段：UNPROCESSED / PRE_ARCHIVED / PENDING_REVIEW / ARCHIVED / NO_ARCHIVE
- 新建 `workflow` 模块：流程类型表 + 环节表（T_DA_FLOW_TYPE/TASK/TASKNODE 同构），环节可配权限角色与回调
- 著录列表按 stage 分页签（未处理/预归档/待审核/已归档），按钮按 grants 渲染
- 批量修改/替换 API（复用批量导入的并发框架，走 Redis 队列）

### P2 检索与并发优化（1 周量）
- ES：门类/密级/期限/年度 **facet 聚合**，检索结果左侧过滤栏
- 同义词表（T_DA_SYNONYM 同构）→ ES synonym filter
- 检索接口加分页游标 + Redis 缓存热查询
- PG 连接池调优 + 批量操作走队列，Web 层全部异步 IO

### P3 利用闭环 + 鉴定/开放/销毁（2 周量）
- 借阅补：归还、外借/查阅状态、利用日志表、打印利用单（前端打印模板）
- 鉴定任务（到期鉴定 → 处置：继续保管/移交/销毁）
- 开放流程：条目开放/原文开放/不开放/再审查 + 开放批次
- 回收站（软删除 + 还原/清空）

### P4 向量库 + RAG / LLM Wiki 接口预留（设计先行，实现按需）
- **向量库选型：pgvector 扩展**（天玑已有 PG16，零新增组件；数据量 <千万级完全够用；如日后上量再迁 Milvus）
- 接口预留三件套（模块边界先立好，防止日后大改）：
  1. `embedding-provider` 接口：`embed(text) -> vector[]`，实现类先用 Ollama（本机 11434 已有 qwen3:32b，可跑 nomic-embed-text），后续可换 API
  2. `rag-service` 接口：`retrieve(query, topK, filters) -> chunks[]`（filters 复用密级/全宗行级权限——**RAG 检索必须过 AccessFilterBuilder，这是与通用 RAG 的本质差异**）
  3. `wiki` 模块：档案知识组织（条目→条目关联、主题聚合），LLM 生成条目摘要/关联推荐走独立 `llm-gateway` 接口
- extractor 抽取文本时同步写 `item_chunks` 表（chunk + embedding + 权限字段），一条流水线两个用途（全文检索 + 向量检索）

### 明确不抄的
- Ext JS 老式 UI、二/三维码、光盘导出、补丁管理、实体密集架可视化（除非做实体档案）

## 五、风险与依赖
- 泰坦 H2 在跑，**只读查询不影响其运行**；不要在泰坦库上做写操作
- 天玑 `60f5c39` 之后 web/extractor 镜像需重打才能带上 P1 改动
- pgvector 需在 tianji-postgres 容器内 `CREATE EXTENSION vector`（PG16 alpine 需换 pgvector 镜像）
