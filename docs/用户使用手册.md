## 1. 快速开始

### 1.1 登录

1. 浏览器（Chrome / Edge 最新两个大版本）打开 `http://<服务器IP>:8080`。
2. 输入「用户名」「密码」，点击「登 录」。
3. 登录成功后进入「工作台」首页。

**成功判据**：页面顶部显示您的姓名、角色与「密级上限」标签；右上角出现「退出」按钮。

**注意**：
- 初始系统只有管理员账号 `admin / Tianji@2024`（登录页有提示）。**admin 是 R0 系统管理员，在案卷 / 件级著录、电子文件、在线预览、借阅申请等业务功能上均无权限**（点击会收到 403 拒绝）——这是权限矩阵生效，不是故障。请管理员先按 §1.3 建立 R1~R4 对应角色的账号，再开展业务操作。
- 首次登录后请立即通知系统管理员重置密码（当前版本界面暂无自助改密入口，见 §8 限制 #6）。
- 连续 5 次输错密码，账号将锁定 30 分钟；登录失败提示统一为「用户名或密码错误」，不区分账号是否存在。
- 无操作 30 分钟（默认会话超时，可由管理员调整）后需重新登录；超时不会强制踢出正在填写的表单，但请养成及时保存的习惯。

## 3. 档案员操作指引（R1 档案管理员 / R2 部门兼职档案员）

> 典型流程：**建全宗 → 配档号规则 → 建案卷 → 卷内著录 → 上传电子文件 → 提交归档**。

### 3.1 全宗管理（新增 / 编辑 / 停用）

**路径**：左侧导航「档案业务 → 全宗管理」。

**新增全宗**：
1. 点击右上角「新增全宗」。
2. 填写：`全宗号 *`（如 `WS`、`001`，全局唯一，创建后不可修改）、`全宗名称 *`、`立档单位`、`起始年度`、`终止年度`（留空表示至今）。
3. 点击确定保存。

**成功判据**：列表出现新全宗，状态为「启用」；若全宗号重复，系统报错且不保存。

**编辑**：列表行点「编辑」（全宗号不可改，其他字段可改）。停用后的全宗不可新增档案，但仍可检索。

### 3.2 档号规则配置与试算

**路径**：左侧导航「档案业务 → 档号规则」（依据 DA/T 22-2015 §5.3）。

**操作步骤**：
1. 「适用全宗 *」下拉选择全宗。
2. 设置「分隔符」（默认 `-`，不能含字母数字）与「流水重置周期」（按年度 / 按卷 / 不重置）。
3. 在「模板编排」表中增删段：全宗号 / 目录号（门类）/ 年度 / 机构 / 保管期限 / 卷号（流水）/ 件号（流水），可设补零位数、前缀字面量、固定值。
   - 规则：模板必须包含至少一个流水段（卷号或件号）。
4. 点击「服务端试算」查看真实序列的下一个档号（**试算不消耗号**）。
5. 确认无误后点击「保存规则」。

**成功判据**：提示「档号规则已保存（仅对新著录生效）」；右侧「服务端试算结果」显示案卷档号与连续 5 个件级档号。

**重要**：规则变更**只影响新著录**，历史档号一律不变；未配置规则的全宗使用系统默认模板。

### 3.3 案卷著录（F-03）

**路径**：左侧导航「档案业务 → 档案著录」。

**新建案卷**：
1. 点击右上角「新建案卷」。
2. 填写：`全宗 *`、`门类`（决定著录字段集，默认"使用全宗默认规则"）、`案卷题名 *`、`责任者`、`年度 *`、`保管期限 *`（永久 / 30年 / 10年）、`密级 *`（公开 / 内部 / 秘密）、`关键词`（逗号分隔）、`备注`。
   - **档号不手工填**：由档号规则自动生成。
3. 点击「创建并取号」。

**成功判据**：提示「案卷已创建，档号 XXX…」，列表新增一行（状态"草稿"）。

**归档**：列表行点「归档」按钮（需归档确认权限），提示「已确认归档，同步 N 件」——卷内全部件级联转为已归档。已归档案卷不可再修改。

### 3.4 卷内文件著录（F-04）

**路径**：案卷列表行点「卷内文件」，进入左右分栏著录页（左侧件列表 / 右侧著录表单）。

**新增件**：
1. 左栏点击「+ 新增」。
2. 按门类字段集填写：`档号`（只读，保存后自动生成）、`题名 *`、`责任者 *`、`文号`、`文件形成日期 *`、`页数`、`关键词`、`备注` 等必填项带 `*`。
3. 右上角点「新增件」（保存）。

**成功判据**：提示「件已创建，档号 XXX…」，左栏列表出现该件（状态"草稿"），卷内自动排序。

**修改**：左栏点击已有件 → 修改表单 → 点「保存修改」。已归档 / 已作废的件为只读。

**提交归档**：选中草稿件 → 点「提交归档」，提示「已提交待归档」。最终入库以案卷「归档」为准。

**作废重编（档号唯一变更通道）**：
1. 选中件 → 点「作废重编」。
2. 填写 `作废原因 *`（至少 5 个字，将记入审计日志）。
3. 点「确认作废并重编」。

**成功判据**：提示「已作废重编：旧档号 → 新档号」。**档号本身不可直接修改**，只能作废后重新取号，全程留痕、不可撤销。

### 3.5 电子文件上传与在线预览（F-08）

**路径**：卷内文件页，选中件后下方「电子文件」区。

**上传**：
1. 点击「选择文件上传」。
2. 系统依次显示：计算文件指纹（SHA-256）→ 申请上传凭证 → 逐片直传（>5MB 自动分片）→ 服务端校验完整性。
3. 支持格式：PDF / 图片 / Office / 音视频 / TXT / EPUB / MOBI，单文件 ≤ 2GB（超限直接报错）。电子书（EPUB/MOBI）与 TXT 入库后自动抽取正文参与全文检索，但**不支持在线预览**（仅可下载原件）。

**成功判据**：提示「上传成功：文件名（SHA-256 …）」，文件列表新增一行，含大小、类型、抽取状态（PENDING → OK / FAILED）、SHA-256 前 20 位。

**抽取与全文索引**：上传后后台自动抽取文本，抽取状态由 `PENDING` 转 `OK` 后，正文才可被全文检索命中。失败的文件可联系管理员重试。

**完整性校验**：文件行点「校验」，提示「完整性 PASS；期望 … 实际 …」即通过（服务端重算 SHA-256 与入库基线比对）。

**在线预览**：点击文件名打开预览弹窗。PDF 可翻页，预览页面叠加水印（用户名 + 时间）并提示「本预览已按要求叠加水印，请勿外传」；预览行为强制写入操作日志。不支持的格式会提示"暂不支持在线预览"。

**删除文件**：文件行点「删除」（需删除权限）。

### 3.6 综合检索（F-05）

**路径**：左侧导航「检索利用 → 综合检索」。结果已按您的密级与数据范围自动过滤，无权条目不会出现。

**全文检索**（Tab「全文检索」）：
1. 顶部输入关键词（可空格分隔多词，检索题名 / 责任者 / 文号 / 全文），回车或点「检索」。
2. 命中片段以高亮显示；每条显示档号、密级、保管期限、开放标识、状态、相关度与耗时。
3. 左侧「分面筛选」可按 全宗 / 密级 / 保管期限 / 年度 / 门类 收敛结果（点击即筛选，再点取消）。
4. 点「高级筛选」展开：密级、保管期限、起始 / 截止年度、排序（相关度 / 日期升降 / 档号升序）、`检索条件名称` + 「保存检索」。
5. 右侧「最近检索」显示最近 8 条（点击回放）；「已保存检索」可回放或删除。
6. 点击题名跳转档案详情页。

**条件检索**（Tab「条件检索」）：
1. 每行选择「字段」（档号 / 题名 / 责任者 / 年度 / 成文日期 / 保管期限 / 密级 / 状态 / 开放标识 / 文号 / 主题词）、「运算」（等于 / 不等于 / 包含 / 属于 / 大于等于 / 小于等于 / 区间 / 为空 / 不为空）与「值」。
2. 可「+ 添加条件」多行，逻辑选 `AND 全部` 或 `OR 任一`。
3. 点「执行检索」。

**成功判据**：结果区显示「共 N 条 · 耗时 X ms」；检索不到时给出可能原因（关键词未命中 / 密级不足 / 数据范围不覆盖）。

### 3.7 回收站

**路径**：左侧导航「档案业务 → 回收站」。案卷 / 文件 / 电子文件删除后进入回收站，默认保留期内可还原（保留天数由参数 `recycle.retention_days` 决定，到期由系统每日 04:00 自动物理清理）。

- **还原**：选中记录点「还原」，提示「已还原到原位置」。若档号已被重新占用会还原失败，需先在著录中处理冲突档号（作废或重编）。
- **彻底删除**：点「彻底删除」并二次确认后**不可恢复**，并记入日志。

### 3.8 统计报表（F-07）

**路径**：左侧导航「统计与运维 → 统计报表」。

- 三个页签：「库存统计」（按保管期限 / 门类分布表）/「接收统计」（按月接收趋势图 + 明细表）/「借阅统计」（总数 / 已归还 / 逾期卡片 + 按月借阅量 + 借阅热度 Top10）。
- 顶部按钮：「导出库存」「导出接收」「导出借阅」，导出 Excel 文件自动开始下载，提示「导出完成，文件已开始下载」。
- 数据按当前用户权限范围统计。

### 3.9 档案鉴定（P3 新增）

**路径**：左侧导航「档案业务 → 档案鉴定」。只对 R1 档案管理员开放（R2/R3 看不到该菜单）。

**它解决什么**：保管期限到了要决定「继续留、延期留、移交走、还是销毁」。销毁必须两人签字（R1 初审 + R4 批准），所以做成「任务 → 明细 → 结论 → 执行 → 审批」五步。

**第一步：建任务**
1. 点右上「新建鉴定任务」，填任务名称。
2. 填起始/结束年度（决定圈哪些年度的档）。
3. 需要时选「纳入的保管期限」（如只鉴定 10 年期）。
4. **「仅鉴定已到期的档案」默认勾选**：永久件不参评，10 年满 10 年、30 年满 30 年才进任务。想全量过一遍就取消勾选。
5. 点「创建并生成明细」。系统自动给任务编号（`JD2026-001`）并生成逐件明细。

**第二步：给结论**
1. 点任务行「明细」打开右侧抽屉。
2. 勾选若干件 → 点「继续保管 / 延期保管 / 移交 / 销毁」。
3. 「延期保管」必须选**新的保管期限**；「销毁」必须填**鉴定意见**（这是销毁清册的依据，系统强制）。
4. 结论可以反复改，只要还没点「执行」。

**第三步：执行（真正改库）**
- 点任务行「执行」并确认。提示会告诉你处理了几件。
- 结果里出现 **「待审批 N 件」** 是正常的：销毁件没批之前**不会**被删。
- 继续保管只留痕（不改业务字段）；延期会改保管期限；移交会打移交标记。

**第四步：销毁审批**
1. 任务行点「提交销毁审批」。
2. R1 在「审批中心 → 我的待办」做初审 → 同意。
3. R4 领导在「审批中心」做终审 → 同意。
4. 通过后系统自动把销毁件**软删除进回收站**（可还原），任务行显示「销毁已批」。

> ⚠️ 销毁不是真删：进回收站后仍可还原。真要物理删除要去回收站做「彻底删除」，那一步才是不可逆。

**任务什么时候算「已完成」**：所有明细都给了结论 **且** 都执行完。只要还有一件「未鉴定」，任务就一直是「鉴定中」——这是为了防止「三千多件没看却显示完成」。

### 3.10 开放管理（P3 新增）

**路径**：左侧导航「档案业务 → 开放管理」。

**它解决什么**：《档案法》要求到期档案开放审核，逐件判定「能不能公开、公开到哪一层」。本系统按批次做，四态结论：

| 结论 | 含义 | 结果 |
|---|---|---|
| 条目开放 | 目录能查，原文不能看 | `open_scope=ENTRY` |
| 原文开放 | 目录 + 原文都能看 | `open_scope=FULLTEXT` |
| 不开放 | 控制使用（含涉密、涉个人隐私） | `open_scope=NONE` |
| 再审查 | 拿不准，转专门小组再看 | 进「再审查队列」，本次不应用标识 |

**操作**
1. 点「新建开放批次」，填名称、年度区间、纳入密级（留空 = 全部密级）。
2. 点批次行「明细」→ 勾选 → 点四个结论按钮之一；「不开放」「再审查」建议填理由（会记入审核记录）。
3. 审完点「提交审批」。**没审完也能提交**：未审的件一律按「不开放」收口（宁可少开放，不可错开放），并记理由「提交时未审核」。
4. R1 在审批中心同意后，开放标识**自动写进档案表**；页面下方「再审查队列」单列待跟进的件。

> 提交后明细锁定不可改。要改只能撤回或作废重开。

## 4. 普通用户操作指引（R3 借阅用户）

### 4.1 检索与查看

同 3.6 节。您只能看到密级不高于您「密级上限」且在授权范围内的档案；秘密级档案检索命中后，需通过借阅审批方可利用。

### 4.2 发起借阅申请

**路径**：左侧导航「检索利用 → 借阅管理」，点右上角「新建借阅申请」。

1. 在「搜索档案（题名/档号）」输入关键词，从「借阅档案 *」下拉中选择目标档案。
2. 填写「借阅目的 *」（**至少 5 个字**）。
3. 选择「借阅方式」：`在线阅览` 或 `原件借出`。
4. 「预计归还日期 *」已按管理员配置的默认借期预填，可修改（借期自借出日起最长 90 天，可续借 1 次，具体以页面提示为准）。
5. 点「提交申请」。

**成功判据**：提示「借阅申请已提交：<单号>」，在「我的申请」页签可看到该单（状态"待审批"）。

### 4.3 跟踪进度 / 续借 / 撤销

- 「我的申请」页签查看全部本人申请；点「详情」查看审批流转记录（第 N 级 · 审批人 · 同意/驳回 · 意见）。
- **续借**：状态为"已借出"且未逾期、未续借过的单据显示「续借」按钮，点击直接生效（无需重新审批），提示「续借成功」。
  - 续借规则（BR-06）：总借期（含续借累计）不超过 90 天；最多续借 1 次；逾期单与待审批单不可续借。
- **撤销**：状态为"待审批"或"已批准"的本人单据可点「撤销」。
- **归还**：本人无需操作归还，由档案管理员登记归还。

### 4.4 片段检索：找「哪段原文提到过」

**路径**：左侧导航「检索利用 → 片段检索」。

用法：在输入框写关键词或一句话描述（至少 2 个字），点「检索」或按 `Ctrl/⌘ + Enter`。

**它会给你什么**：命中档案的**档号 + 正文原文片段 + 密级**，命中词高亮，点「查看条目」可直接跳进该档案。每段依据都标了出处，你可以自己核对原文。

**它不会给你什么（重要）**：

- **不生成答案、不做总结**。页面只把原文摘出来给你看 —— 因为档案要的是凭证，改写过的句子不能当依据。
- **没有依据时会明确写「无依据」**，不会猜、不会编。看到「无依据」有三种可能：① 你要的内容真不在这批档案里；② 该档案还没抽取正文（管理员可在「档案管理」里看抽取状态）；③ 内容超出你的密级或授权范围。
- 结果里**不可能**出现你没权限看的档案：系统在检索前就按密级和数据范围过滤，命中后还会回库再核对一次。

**搜不到怎么办**：换更贴近原文的说法（片段检索是按字面词匹配，不是按"意思"匹配）；确认目标档案已完成正文抽取；确认你的密级上限够。

### 4.5 智能问答与知识库（P4 新增）

**路径**：左侧导航「检索利用 → 档案知识库」。

**和「片段检索」的区别**：片段检索只把原文摘给你看；知识库问答会用本地大模型**读这些片段并组织成一句人话回答**，同时给出 `[1][2]` 引用，点引用能跳回原档。**答不出就只给片段，不编。**

**怎么用**
1. 在提问框写问题 → 点「提问」。问题写得越接近档案原文越好，比如「劉克莊《一剪梅》中「束縕宵行十里強」的下一句是什麼？」
2. 等 3–25 秒（本地模型在算），回答出现后看三样东西：
   - 徽标：「向量+词法混合召回」（表示走了语义 + 字面双路）或「词法召回」（模型不可用时的降级）
   - 耗时
   - 回答正文里的 `[n]` 与下方片段序号对应
3. 页面顶部会显示当前向量库状态（`pgvector` / 嵌入模型 / 生成模型 / 已建向量条数）。显示「数组回退」说明向量扩展不可用，检索会自动走词法，功能不中断。
4. 页面中部的「主题词」是按你可见范围统计的馆藏分布，点一个词就直接用该词提问。

**问馆藏里没有的内容会怎样**：回答会明确写「根据提供的档案片段，未提及…」，**不会**用模型自己的常识编一段。演示库里全是古籍与民国文献，所以像「电子文件四性检测包括哪些内容」这类问题必定答「未提及」——这不是故障。

**你能看到什么，取决于密级**：问答的召回在数据库层就按你的密级和数据范围过滤，**无权档案的原文不会进入模型**，因此也不会出现在回答里。同一句话，R1（秘密级）和 R3（内部级）可能得到不同长度的答案 —— 这不是 bug。

**条目互链（Wiki）**：档案详情页可给两件档案建立关系（同案卷 / 同主题 / 相关），也可点「自动关联」让系统给候选；「生成摘要」用本地模型给单件写 3~5 句提要。

## 5. 审批人操作指引（R1 档案管理员一级审批 / R4 领导二级终审）

### 5.1 审批借阅申请

**路径**：借阅管理页 → Tab「待我审批」（也可在「全部借阅单」中对"待审批"单点「审批」）。

1. 点目标单据行的「审批」，弹窗显示：单号、题名、密级（秘密级标注"需两级审批"）、借阅目的、已审批记录。
2. 填写「审批意见 *」（**至少 2 个字**，必填）。
3. 点「同意」或「驳回」。

**成功判据**：
- 普通密级：提示「审批通过，已完成全部审核」，单据转"已批准"。
- 秘密级（两级）：第一级通过提示「一级审批通过，流转至二级审批」，单据保持"待审批"，等第二级签署。
- 驳回：提示「已驳回」，单据转"已驳回"。

**规则**：审批意见必填；**申请人不能审批自己的单据**；两级审批必须由**不同审批人**完成，同一人在同一单据上不可重复签署；第二级（终审）仅 R4 领导/查档审批人可办理（界面弹窗文案写的是"档案管理员 → 系统管理员"，以本条实际权限为准）。

### 5.2 借出登记（R1）

状态为"已批准"的单据，行内点「登记借出」，提示「已登记借出」，单据转"已借出"，借期开始计算。

### 5.3 归还登记（R1）

状态为"已借出"或"逾期"的单据，行内点「归还」：
1. 弹窗确认档案信息；逾期单会警示「该单据已逾期，请核实是否产生逾期记录（系统将写入审计日志）」。
2. 可选填「归还说明」。
3. 点「确认归还」，提示「归还登记完成」，单据转"已归还"。

**逾期与催还**：系统每日自动扫描，到期前按 `borrow.overdue_remind_days`（默认 3 天）提前提醒，逾期单据自动标红显示"逾期"标签；借阅统计中计入逾期数。

### 5.4 审批中心（P3 新增：所有审批流的统一入口）

**路径**：左侧导航「检索利用 → 审批中心」。R1 与 R4 可见，R2/R3 看不到。

页面有三个页签：

| 页签 | 用途 |
|---|---|
| 我的待办 | 轮到你处理的单据。**按岗位派单**：同角色任何一人都能看到并处理，不必等某个指定的人 |
| 审批实例 | 所有审批单的状态、当前环节、发起人、时间线（点开可看每一步谁批的、意见、时间） |
| 流程配置 | 流程定义的环节流向。可看可改，但**改回调会直接改变业务行为**，非必要不要动 |

**处理一单**：在「我的待办」点「同意」或「驳回」。

- 同意：推进到下一环节；你是最后一环就整单通过，系统随即执行业务动作（如应用开放标识、执行销毁）。
- 驳回：**必须填意见**，填完流程终止，单据回到发起人手里（可修改后重新提交）。
- 发起人可「撤回」自己还没走完的单。

**你能看到哪些待办**：只看到「节点角色 = 你的角色」**且**「你具备该业务审批权限」的单据，两个条件缺一不可。所以 R4 有审批权但看不到「档案管理员初审」这一环（那环归属 R1），R1 同意后才会流转到 R4。

**内置两条流程**：

| 流程 | 环节 | 通过后自动做什么 |
|---|---|---|
| 开放批次审批 | R1 档案管理员审核 | 把开放结论写进档案表（条目/原文开放标识） |
| 鉴定销毁审批 | R1 初审 → R4 领导批准 | 把销毁件软删除并进回收站 |

> 审批超时不会自动通过 —— 销毁不可逆，宁可卡住等人，也不自动放行。

## 6. 系统管理员操作指引（R0）

### 6.1 用户与角色

**路径**：左侧导航「系统管理 → 用户与角色」（两个页签）。

**新建用户**（「用户」页签 → 点「新建用户」）：
1. 填写：`用户名 *`（≥3 字符）、`显示名 *`、`初始密码 *`（≥8 位）、`密级上限`（公开 / 内部 / 秘密）、`状态`、`角色`（可多选 R0~R4）、`数据范围`（全部 / 全宗 / 机构 / 本人）。
2. 保存后提示「用户创建成功」。

**其他操作**：
- 「编辑」：修改显示名、状态、密级上限、角色。**权限与密级变更即时生效**（主动失效通道，被撤销权限的用户下一次请求即被拒绝并记日志）。
- 「停用」：停用后该账号无法登录。
- 「重置密码」：新密码 ≥8 位，提示「密码已重置（请通知用户尽快修改）」。
- 「数据范围」：为用户授权可见的全宗 / 机构范围。

**角色权限矩阵**（「角色权限」页签）：选择角色后，按「功能域 × 操作（查 / 著 / 审 / 改 / 删）」勾选，保存后立即生效并刷新在线用户权限快照。

### 6.2 数据字典

**路径**：「系统管理 → 数据字典」。统一维护保管期限、密级、门类、利用目的等下拉选项。

- 按「字典类型」分组展示；每项含排序、字典码、显示名、状态、是否内置。
- 新增：选择 / 输入类型，填写字典码与显示名后保存。
- **内置项仅可停用不可删除**；被业务引用的字典项禁止删除。

### 6.3 系统参数

**路径**：「系统管理 → 系统参数」。参数定义以后端 `PARAM_DEFS` 为唯一源，按分组展示：借阅规则 / 预览与下载 / 安全策略 / 回收站 / 备份 / 日志与审计 / 文件 / 导入 / 检索 / 内容抽取。

**修改参数**：
1. 搜索 key / 名称定位参数，点该行「修改」。
2. 弹窗显示影响范围（消费方）与合法区间；枚举型以下拉选择。
3. 点「保存」：系统先做**跨参数依赖预检**，存在冲突时一次性列出全部冲突，标注「（阻断）」的必须修正后才能保存，**越界值不会被静默保存**。

**注意事项**：
- 带「高 / 中」标签的参数（🔴/🟡 确认级别）为单位制度类参数，修改前请与档案 / 保密部门确认；变更 100% 留痕（操作人 / 时间 / 旧值 / 新值）。
- 标「固化」的参数（如 `log.retention_years` 日志保留年限）为合规固化项，**出厂口径不可修改**。
- 生效口径：安全类与预览水印 / 下载控制类参数下一请求即时生效；借阅类参数仅对新申请 / 新续借生效，不回溯在途单据；回收站 / 备份 / 日志保留类由定时任务按当前值增量处理。

### 6.4 操作日志

**路径**：「系统管理 → 操作日志」。检索 / 预览 / 下载 / 登录 / 权限变更 / 审批 / 删除 / 作废 / 导出 / 备份等关键操作**强制留痕**，日志只追加不可修改。

- 条件筛选：开始 / 结束日期、动作、对象类型、关键词（用户 / 对象 ID）。
- 点「导出 CSV」导出查询结果。
- 日志保留年限默认 3 年（固化参数）。

### 6.5 备份与恢复

**路径**：「统计与运维 → 备份恢复」。

**手动备份**：
1. 选择「备份范围」：全量备份（数据库 + 对象存储）/ 仅数据库 / 仅对象存储 / 仅元数据。
2. 点「立即备份」，提示「备份任务已入队，执行完成后此处会自动刷新」。

**成功判据**：「备份记录」表新增一行，状态转"成功"，含文件名、大小、数据库 / 对象存储分项状态、起止时间；左上「备份成功率」卡片更新。

**恢复校验**：状态为"成功"的记录点「恢复校验」，弹窗逐项显示校验结果（备份对象可达 / 数据库连接正常 / 文件大小一致），并附《恢复指引》。**恢复本身是破坏性操作，由运维在服务器侧按指引执行，系统内不提供一键恢复。**

**注意**：全量备份依赖 Docker 容器（pg_dump / 对象存储同步）；容器不可用时自动**降级为元数据快照**并在结果中明确标记，不会伪装成完整备份。

### 6.6 检索索引维护

综合检索页右上角「重建索引」按钮（仅管理员可用）：全量重建全文索引，完成后提示「索引重建完成：成功 N，失败 M」。适用于抽取文本入库后检索未命中、或索引异常的修复场景。

### 6.7 向量库与模型维护（P4 新增）

**看状态**：左侧「档案知识库」页顶部，或直接 `GET /api/rag/status`。关键字段：
- `vectorStore: PGVECTOR` 表示 pgvector 可用；`embeddingAvailable: true` 表示嵌入模型在线
- `chunkCount / itemCount`：已建切片数与覆盖件数
- `embeddingModel / llmModel`：当前用的模型名（由 `.env` 决定）

**重建向量库**：知识库页点「重建索引」，或

```bash
TOKEN=$(curl -s -X POST http://127.0.0.1:3000/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"Tianji@2024"}' | python3 -c "import sys,json;print(json.load(sys.stdin)['data']['accessToken'])")
curl -X POST http://127.0.0.1:3000/api/rag/reindex -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" -d '{"limit":500}'
```

- 不带 `limit` = 全量；带 `limit` 可分批跑（每批 500 件约 1 分钟）
- 全量 3468 件约 15–20 分钟（约 19 块/s）；期间检索照常可用
- `force: true` 才会重切已有切片；默认只补缺失的件

**换模型要四步**（漏一步就查不出东西）：① 改 `.env` 的 `EMBEDDING_MODEL` / `EMBEDDING_DIM` → ② 同步改 `item_chunk.embedding` 的向量维度（`ALTER TABLE … TYPE vector(N)`）→ ③ 全量 `reindex` → ④ `GET /api/rag/status` 确认维度一致。

**模型挂了会怎样**：不会 500。嵌入不可用时自动降级为纯词法召回 + 抽取式摘要；生成模型不可用时只返回片段与引用。页面顶部会给出提示条。

## 7. 常见问题（FAQ）

**Q1：登录提示「用户名或密码错误」？**
先确认账号未停用；连续输错 5 次账号锁定 30 分钟，请等待后重试或联系管理员重置密码。

**Q2：能正常登录、能检索，但文件传不上去（一直卡在"申请上传凭证"或分片上传失败）？**
电子文件**不经过应用服务器**，浏览器是拿预签名 URL 直连对象存储上传的。对象存储 S3 网关默认发布在**服务器的 8333 端口**（预签名地址默认形如 `http://<服务器IP>:8333/...`）。若您的电脑到服务器 8333 端口网络不通（防火墙 / 安全组 / 预签名地址配置成了内网不可达地址），就会出现"能登录能检索但传不上"的现象。**请联系系统管理员处理**；用户机上快速定位的三项自检判据与失败解读见《离线部署手册》§6.3（其"3/3 红"即本情形）。

**Q3：上传成功了，为什么检索全文还搜不到？**
上传后系统要经历"文本抽取 → 写入全文索引"两个后台步骤，抽取状态在文件列表可见：`PENDING`（处理中）→ `OK`（可检索）。等待状态转 OK 后再检索；若长时间停在 PENDING 或转 FAILED，请联系管理员。纯图片扫描件可能没有可抽取的文本层，属正常现象。

**Q4：检索结果比预期少？**
三步排查：① 检查自己的「密级上限」（检索页右上显示）——秘密级档案需要相应密级授权；② 检查数据范围（全宗 / 机构授权）；③ 确认目标档案状态不是"草稿 / 已作废"。检索不到无权条目是权限设计使然，不是故障。

**Q5：想修改已入库的档号？**
档号一经生成不可直接修改，唯一通道是详情页「作废重编」（填原因 ≥5 字，全程留痕，旧号作废、新号按当前规则生成）。

**Q6：看不到「续借」按钮？**
仅当单据状态为"已借出"、未逾期、且您是申请人、尚未达到续借次数上限（默认 1 次）时才显示。逾期单需先归还再重新申请。

**Q7：点「下载原件」被拒绝？**
当前下载控制参数 `preview.download_mode` 默认为 `approval`（需审批后下载），未获下载授权的账号会被明确拒绝并留痕——这是**保密防护的预期行为**（fail-closed），不是故障。如单位业务需要下载，请联系管理员按制度授予下载权限。

**Q8：预览打不开或没有水印？**
预览依赖对象存储网络可达（同 Q2 的 8333 端口）。水印开关与内容由管理员在「系统参数 → 预览与下载」中配置，变更下一请求即时生效；涉密场景不建议关闭水印。

**Q9：填了一半的著录表单突然要重新登录？**
默认会话 30 分钟无操作超时（参数 `security.session_timeout_min`，可由管理员调整）。超时不会踢出已保存的数据，但未保存的表单内容会丢失，请及时点「保存修改」。

**Q10：「片段检索」结果显示「无依据」是怎么回事？**
说明在你**有权访问**的档案正文里没匹配到相关片段。三种常见原因：① 内容确实不在这批档案里；② 该档案还没抽取正文（看档案详情的抽取状态）；③ 超出你的密级或授权范围（越权内容不会返回，只会表现为"搜不到"）。系统不会为了"看起来能用"而编造答案 —— 详见 4.4 节。

## 8. 已知限制（诚实边界）

以下为当前版本**实际存在**的能力边界，均经代码与部署配置核实，如实告知、不做美化：

| # | 限制 | 说明 |
|---|---|---|
| 1 | 片段检索**不生成答案** | 「片段检索」只返回档号 + 原文片段 + 密级，`answer` 字段恒为空——档案要凭证，改写过的句子不能当依据。需要成句回答请用「档案知识库」的**智能问答**（P4 已交付，回答带 `[n]` 引用可回溯）。命中为空时明确显示「无依据」，**绝不编造**。 |
| 2 | 下载放行链路未实现 | 下载控制默认 `approval`（需审批）模式，但"审批通过后授予下载权限"的授权写入链路尚未实现（上线前闭环项 L2）。所有未授权账号下载均被正确拒绝（fail-closed），但**尚无账号能通过审批真正下载**。 |
| 3 | extractor / backup 容器无 healthcheck | Docker Compose 中 postgres / elasticsearch / seaweedfs / redis / api / web 均配置了健康检查，**文本抽取（extractor）与备份（backup）两个容器没有**；其异常需通过抽取状态、备份记录间接发现。 |
| 4 | 检索结果无导出按钮 | 综合检索页未提供"导出检索结果 Excel"入口（PRD F-05 规划项）；当前可导出的是统计报表三类 Excel 与操作日志 CSV。 |
| 5 | 条目批量修改无界面入口 | 后端已实现批量修改接口（`POST /archive/items/batch-update`），前端暂无对应操作入口。 |
| 6 | 无自助修改密码入口 | 后端已预留修改密码接口，界面暂未接入；忘记密码请联系管理员在「用户与角色」中重置。 |
| 7 | 借阅审批提示文案与实际不符 | 借阅申请弹窗提示"秘密级需两级审批（档案管理员 → 系统管理员）"，实际后端第二级终审仅 R4 领导/查档审批人可签，且两级须不同审批人。以本手册第 5.1 节为准。 |
| 8 | 全量备份依赖容器环境 | 无 Docker 容器时"全量备份"自动降级为元数据快照（结果明确标记），不能替代完整的数据库 + 文件备份。 |
| 9 | 统计报表仅 Excel 导出 | 未提供 PDF 导出与 A4 打印按钮（PRD F-07 规划项）。 |
| 10 | 工作台「鉴定到期」卡片仍为占位 | 鉴定功能本身已可用（左侧「档案业务 → 档案鉴定」），但工作台首页那张"鉴定到期 N 件"卡片还没接数据，恒为 0。以鉴定页的任务列表为准。 |
| 11 | 部分检索增强未实现 | 同义词扩展、检索历史、保存检索**已可用**；PRD 规划的订阅推送、时间轴 / 卡片视图、拼音首字母检索、相似档案推荐未实现。 |
| 12 | 编研 / 导入导出 / 消息中心为 P1 范围 | 档案编研（F-15）、可视化报表设计器（F-16）、批量导入导出与移交接收（F-17）、通知消息中心（F-21）等属第二迭代，本期未交付；存量数据批量导入由运维使用 `apps/cli-migrator` 命令行工具完成，不经界面。 |
| 13 | 大文件为逻辑边界 | 上传支持 2GB 分片直传，但 2GB 真实大文件与断点续传尚未经实测验证（demo 仅验证 >5MB 分片链路）。 |
| 14 | 开放标识仅在件详情页显示 | 详情页头部在密级/状态旁显示「条目开放 / 原文开放」徽标（`open_scope`）；**检索结果列表里还没有**，检索页暂不区分开放粒度。 |
| 15 | 再审查队列只读 | 标记「再审查」的件会进入开放管理页下方的队列，但暂不支持"一键转新批次"，需人工另建批次处理。 |
| 16 | 审批流无图形化设计器 | 流程与环节在「审批中心 → 流程配置」以表格方式维护（名称/角色/权限域/回调），不是拖拽画布；超时只告警不自动升级。 |

## 9. 附：常用术语

| 术语 | 含义 |
|---|---|
| 全宗 | 一个立档单位全部档案的总称，以唯一「全宗号」标识（DA/T 22-2015 §5.2） |
| 档号 | 档案的唯一编号，由档号规则自动生成，入库后不可修改（仅可作废重编） |
| 密级 | 公开 / 内部 / 秘密 三档，决定谁能看到该档案 |
| 保管期限 | 永久 / 30年 / 10年 |
| SHA-256 | 电子文件的完整性指纹，入库必记，用于完整性校验 |
| 抽取状态 | 电子文件文本抽取进度：PENDING（处理中）/ OK（完成，可全文检索）/ FAILED（失败） |
| 数据范围 | 用户可见的档案边界（全部 / 全宗 / 机构 / 本人） |
