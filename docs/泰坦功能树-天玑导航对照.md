# 泰坦 DARMS 功能树 × 天玑导航对照

> **来源**：泰坦本地实例 H2 库 `T_S_PRIVILEGE` 全量导出（4394 条权限点，339 个可打开页面）。
> **口径**：按 `CODE` 前缀还原树结构；`URI` 非空的节点视为「页面」，其余为页面内按钮/状态。
> **复刻范围**：`JZQB`（增强版，63 页）+ `LYPT`（利用平台，16 页）共 79 页；
> `FZST / JBZB / JYBB / SJCB / CPSZ` 是同一产品的其他版本/功能池，页面与本套重复，不单独建导航。
> **状态图例**：
> - `✅` 独立入口（导航有一级菜单项，功能完整）
> - `🔗` 合并入口（同一页面的页签/视图，导航可达）
> - `🆕` 本期新增入口
> - `⚪` 未覆盖

> 覆盖率按「页面是否可达」计算。合并入口意味着从该导航项进入后，通过页签/视图切换即可完成泰坦对应页面的动作，
> 不再单独占用一个侧栏菜单（例如泰坦的「照片档案 / 录音档案 / 录像档案」在本系统内是档案著录的门类视图）。
